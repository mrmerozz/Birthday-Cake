# Birthday Cake

An interactive birthday web app - type in a name and age, and a cake shows up with the right number of candles. Tap the cake to blow them out and you get confetti, floating balloons, and a short message. The colors even change depending on the age you enter.

Made with plain HTML, CSS, and JavaScript. It uses the canvas-confetti library for the confetti effect.

## What it does

- Enter a name and age to start
- A cake appears with candles matching the age
- Tap the cake to blow out the candles
- Confetti and balloons go off, with a personalized message using the name and age
- The theme and colors shift based on the age range

## Running it

It's a static site, so just open `index.html` in a browser. It's also live on GitHub Pages:

https://mrmerozz.github.io/Birthday-Cake/

Built with HTML, CSS, and vanilla JavaScript plus canvas-confetti.
